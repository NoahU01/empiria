Stoßrichtungen

Wenige Richtungen, klar begründet.

Aus der Analyse der Ausgangslage entstehen wenige Stoßrichtungen. Jede benennt, was sie verändert, und die Kriterien, an denen sich ihre Wirkung erkennen lässt.

Wie sie entstehen

Jede Richtung hat eine Herkunft.

Eine Stoßrichtung entsteht aus einer Kombination der SWOT-Felder: eine Stärke, die auf eine Chance trifft – oder eine Schwäche, die ein Risiko verschärft. Das macht nachvollziehbar, warum sie auf der Liste steht und warum andere nicht.

Ableitung

In Arbeit

Trifft eine Stärke auf eine Chance, wird sie ausgebaut. Trifft eine Schwäche auf ein Risiko, wird sie abgesichert. Aus diesen Kombinationen entstehen die Kandidaten für die Auswahl.

Auswahl

In Arbeit

Drei bis fünf Richtungen – mehr kann niemand gleichzeitig verfolgen. Was nicht ausgewählt wird, wird nicht vergessen, sondern bewusst vertagt.

Nachweis

In Arbeit

Zu jeder Richtung gehört ein Satz dazu, woran man in einem Jahr erkennt, dass sie gewirkt hat. Ohne diesen Satz bleibt sie eine Absichtserklärung.

Das Ergebnis

Die Richtungen der SV Akademie.

Noch offen

Offen

Die Richtungen stehen fest, sobald die Ist-Analyse ausgewertet ist. Danach stehen sie hier – jede mit Herkunft, Lücke und Nachweis.

Reihenfolge

Offen

Was zuerst, was danach, was bewusst später. Die Reihenfolge ist Teil der Strategie, nicht ihre Umsetzung – die Termine dazu stehen im Meilensteinplan.
